1. RESUMEN EJECUTIVO

El presente documento detalla la solución tecnológica diseñada para digitalizar, automatizar y optimizar la gestión de las Órdenes de Trabajo (OTs) de mantención hospitalaria. La plataforma MedicalOT elimina la dependencia de planillas manuales, centralizando la planificación, ejecución, seguimiento y análisis de recursos técnicos.

Objetivo Principal: Pasar de estimaciones manuales a datos duros y trazabilidad real, controlando HHs planificadas vs reales y la oferta real de técnicos disponibles.

La solución se entrega como un servicio administrado en la nube (Cloud-Native), garantizando alta disponibilidad, seguridad de datos y escalabilidad sin requerir infraestructura física ni personal informático dedicado por parte del Hospital. El desarrollo se ejecutará bajo una metodología ágil intensiva de 3 semanas.

2. ARQUITECTURA TECNOLÓGICA

La plataforma se construye sobre una arquitectura moderna, segura y desatendida (*Serverless/Managed Services*), asegurando estabilidad y rendimiento.

Componente Tecnología / Servicio Beneficio
Backend PHP 8.2+ Lenguaje robusto, estándar industrial para aplicaciones empresariales.
Base de Datos MySQL 8.0 (Gestionado) Alto rendimiento, transaccional y alojado en servicio gestionado.
Frontend HTML5, CSS3, JS Vanilla Optimizado para velocidad de carga y compatibilidad total.
Infraestructura Railway.app Plataforma PaaS que gestiona servidores, balanceo y escalamiento automático.
CI/CD GitHub + Railway Despliegue automático al confirmar cambios (Zero Downtime).

Seguridad y Respaldo

  • Autenticación Robusta: Sistema de login inteligente con identificación de roles (Hospital, Vertical, Técnico).
  • Protección de Datos: Conexiones cifradas (HTTPS), validación estricta contra inyecciones SQL/XSS.
  • Respaldos Automatizados: Copias de seguridad diarias automáticas de la base de datos.

3. ALCANCES FUNCIONALES (MÓDULOS)

La plataforma consta de 8 módulos integrados que cubren el ciclo de vida completo de la OT:

Módulo 1: Acceso Seguro y Roles Inteligentes

  • Login único con detección automática de perfil.
  • Admin Hospital: Vista global, KPIs estratégicos.
  • Jefe Vertical: Gestión de su equipo específico.
  • Técnico: Ejecución de OTs y reporte de avances.

Módulo 2: Carga y Validación SIC

  • Importación masiva desde archivos .CSV generados por el sistema SIC.
  • Motor de validación automático (detecta duplicados y valida integridad).
  • Sincronización de catálogos (Equipos, Áreas, Protocolos) en tiempo real.

Módulo 3: Visión Global de OTs

  • Tabla dinámica interactiva con todas las OTs cargadas.
  • Buscador inteligente y filtros avanzados (Estado, Especialidad, Mes).
  • Paginación eficiente para miles de registros.

Módulo 4: Planificador de Recursos y HHs

  • Vista Calendario Hotelero semanal de carga horaria.
  • Asignación Drag & Drop de OTs a franjas horarias.
  • Cálculo automático de distribución de HHs según periodicidad.

Módulo 5: Tracking y Seguimiento

  • Línea de tiempo (*timeline*) de estados por OT.
  • Registro de inicio/fin con timestamp y carga de evidencias (fotos/PDF).
  • Reporte de incidencias (falta material, accesos).

Módulo 6: Presentación y Estado

  • Panel visual minimalista para supervisores.
  • Indicadores de progreso por OT (semáforo verde/amarillo/rojo).

Módulo 7: KPIs y Reportes Gerenciales

Incluye 5 indicadores clave pre-configurados:

  1. Cumplimiento SLA (% OTs cerradas a tiempo).
  2. Eficiencia de Horas (HH Presupuestadas vs Reales).
  3. Volumen de Trabajo (OTs cerradas por mes/especialidad).
  4. Carga de Recursos (% ocupación de grupos).
  5. Top Incidencias (problemas recurrentes).

Módulo 8: Mantenedor de Recursos y Verticales

  • Gestión jerárquica: Verticales -> Grupos -> Técnicos.
  • Control de disponibilidad real (vacaciones, licencias).
  • Cálculo de "Oferta de HHs" disponible realmente.
