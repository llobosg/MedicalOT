# MedicalOT - Sistema Gestión de Ordenes de Trabajo Hospitalarias

- Carga de datos desde SIC
- Asignación de OT
- Tracking OT
- Gestión de estados, KPIs, SLA, Contratistas, Recursos, Grupos de trabajo
- Roles: Hospital, supervisor contratista, técnico

Desarrollado con PHP + MySQL + Railway.

---

## 🔧 Requisitos

- PHP 8.0+
- MySQL 8.0+
- Composer (para dependencias futuras)

## 🚀 Despliegue

Este proyecto está diseñado para desplegarse en **Railway.app**.

1. Crea un nuevo proyecto en Railway
2. Conéctalo a este repositorio
3. Railway detectará automáticamente `railway.toml` y `public/`
